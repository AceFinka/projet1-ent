# Projet 1 (Forked du Laboratoire 3 fait avec Maximr)
## Description
Notre application permet d'effectuer la conversion des mesures de différents modèles. Les modèles disponibles sont la distance, le volume, le poids, la température, le temps et la puissance.

## Instruction d'installation
Voici les instructions pour effectuer une installation adéquate de notre application :

1. Copier le dépôt Git sur votre ordinateur local.
2. Aller sur le répertoire Git copié localement.
3. Ouvrir un terminal dans le répertoire.
4. Utiliser la commande **npm.cmd run dev** dans le terminal pour lancer le serveur.
5. Prendre en note l'adresse HTTP de l'application affichée sur le terminal une fois le serveur lancé.
6. Rechercher sur un navigateur web l'adresse HTTP de l'application local.

## Fonctionnalités ajoutées
Les fonctionnalités ajoutées durant ce laboratoire sont deux nouveaux modèles de conversion pour les mesures de temps (secondes, minutes, heures, jours, mois, années) et de puissance (watts, kilowatts). Ces options de conversion fonctionnent identiquement aux précédentes options comme la distance ou le volume.
